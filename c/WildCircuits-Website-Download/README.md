# WildCircuits FTC 36611 — Final site

Extract the ZIP, then open index.html. For hosting, upload all files and assets together. Pages: Overview, Crew, Results, Schedule, Robot, Sponsors and Contact.

Only the supplied robot photograph is used. The roster includes Deepanshu Natte; no role was supplied for him, so the site lists him as a team member.

Results: the Holmdel snapshot is sourced from FIRST’s qualification match records for USNJSOM1 on October 24, 2026. Scores are alliance totals. The FTC Scout adapter requests the documented 2026 event and match endpoints, caches responses for 15 minutes and supports a manual refresh. The API could not be reached from the authoring environment, so live responses could not be verified. The snapshot, navigation and local assets work independently of that service.

Instagram is an expandable horizontal panel at the top of Overview, with a permanent direct link. Instagram controls the embed’s availability. The sponsor form prepares an email draft; it does not send automatically.


Update: the slogan is Wired to dominate. The top media panel includes Instagram and a YouTube player with the three match videos published at youtube.com/@WildCircuitsFTC. Video IDs: TOHePvfkUqU, jBR4Bf_Bw0c, RYQPCFCLXb8. YouTube loads only when the media panel is expanded and never autoplays. Both services retain direct links if embeds are unavailable.

When opened as a local file, YouTube uses a linked video thumbnail because embedded playback can require a hosted page referrer. On an HTTP(S) host, opening the media panel loads the embedded player. Match buttons work in both modes. External content still depends on the provider and an internet connection.
